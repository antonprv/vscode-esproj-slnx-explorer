# SLNX Solution Explorer

Минимальное расширение VS Code / VSCodium, которое:

1. Само парсит `.slnx` (XML), не полагаясь на чужие расширения — поэтому
   не важно, `.esproj` там, `.csproj` или что-то ещё неизвестное.
2. Строит дерево: Folder/Project из `.slnx` как есть.
3. Для каждого узла-проекта — не пытается «понять» формат проекта,
   а просто показывает содержимое папки, где лежит файл проекта
   (`node_modules`, `bin`, `obj`, `.git` скрыты).
4. Клик по файлу — открывает его как обычный текстовый документ.

Это осознанно "глупое" решение: вместо того, чтобы разбирать MSBuild-специфику
`.esproj`/`.csproj` (система project system у каждого своя и не документирована
публично), просто отображаем реальную файловую структуру рядом с файлом
проекта — этого достаточно, чтобы Node.js-проект был виден и с ним можно
было работать.

## Сборка

```bash
npm install
npm run compile
```

## Отладка (F5)

Открой папку `slnx-explorer` в VS Code / VSCodium → `F5` → запустится
Extension Development Host с активным расширением.

## Упаковка в .vsix и установка в VSCodium

```bash
npm install -g @vscode/vsce   # если ещё не стоит
vsce package
```

Появится файл `slnx-explorer-0.1.0.vsix`. В VSCodium:

`Extensions` → `...` (меню) → `Install from VSIX...` → выбрать файл.

Либо через терминал:

```bash
codium --install-extension slnx-explorer-0.1.0.vsix
```

## Использование

* Открой папку с `.slnx` — расширение найдёт файл автоматически
  (или через кнопку "Открыть .slnx файл..." на панели, если файлов
  несколько или их не нашли).
* Иконка в activity bar (слева) откроет панель "SLNX Solution".

## Возможные доработки
